# Plata (Compose Multiplatform)

Android, iOS and web app built from the Plata design system. Shared UI lives in `shared/src/commonMain`; `androidApp`, `iosApp` and `shared/src/wasmJsMain` are thin entry points.

See [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) for the package layout, tokens, build and screenshot commands.
